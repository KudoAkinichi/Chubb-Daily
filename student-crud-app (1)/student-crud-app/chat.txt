## 🏗️ Project Structure:

- **Controller** - REST API endpoints (Add, Update, Delete, Search)
- **Service** - Business logic
- **Repository** - Database operations
- **Model** - Student entity (id, name, email, course, age)
- **H2 Database** - In-memory database (learning ke liye perfect)
